Saved WikiArt pages for task 9 (web scraping)

These pages were saved from wikiart.org on 2026-11-20 so the scraper (scrape.php) can be built and tested
without ever opening the real web site. scrape.php only reads the files in this folder.

Artists (3):  edouard-manet.html, berthe-morisot.html, gustave-caillebotte.html
Paintings (5 per artist): <artist>__<painting>.html, for example edouard-manet__olympia-1863.html
Pictures: each painting page has a .jpg with the same name next to it (the page's main image)

To use different pages (for example the sample pages from the professor), save them into this folder
("Save Page As" in the browser). Artist pages and painting pages are told apart by what is inside them,
so the file names do not matter. Put the painting's picture next to its page with the same name and .jpg,
or save the page as "Webpage, Complete" so the picture is in the _files folder.
