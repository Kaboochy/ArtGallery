# ArtGallery

## Description
Design and Implement Web System/site by each Team (Prof. Min) 

This task is to design and implement web system/site (Art Gallery) by each team.

In your team meeting, your team will discuss, decide, specify, design, and implement the system (including several web pages and database tables for gallery, artist, artwork, log of user login/session, user and password, user profile of viewer or admin).

Your team task is:

To design, implement, document, and deliver a web system for product listing (of artworks) with user ability to view, add, delete, update a product and do ad-hoc query and report.

To provide the user management including authentication (login and password).

To implement the system in Xampp

To make group effort to do: to determine each unit of work, to review status and issue, to code review (pair-effort), to do testing, to document the system, etc.

To deliver (outcome):

1. The working system with all the codes (in zip file and readme file to guide anyone step by step to build/construct the web site using xampp).
2. Project Plan document (see the sample) at the end of the project phase (and how much in per cent of each part of the system is done or not done and by whom),
3. Project Technical document (see the sample) with cover page, table of contents, with heading and subheading for each part of the web system including code listing and screenshots, system architecture for overview of the system and specification with use-cases, sql tables list and description, sql database/tables exported in sql files, a table or a directory of each file in the system), Video tutorial for the system overview and tutorial,
4. Video tutorial of the web system (how to build and to start or stop the system, how to set up database/tables, to show the flow of the system from log in to log off and major functions (of view, add, delete, update, …), to survey or explain briefly each file or folder in the system.
5. System Demo to TA/Grader (and a penalty if not done or poorly done).
